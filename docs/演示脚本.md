# 演示视频逐镜脚本（5–8 分钟 · 1080p · 普通话）

> 录制提示：Win+G（Xbox Game Bar）或 OBS 均可；分段录制，每段录完看一眼再录下一段，出错只重录当前段。全程鼠标慢一点，页面切换留 1 秒停顿。语速约每分钟 220 字，台词按段照读即可。演示地址：http://47.93.121.0:8080

---

## 0:00–0:40 开场（约 150 字）

**画面**：全屏打开 http://47.93.121.0:8080 停在文献库首页，右上角显示"后端已连接"。

**台词**：
"大家好，我是梁洲源。我的作品是《智领科研·意图驱动——全流程科研助手 Agent》。这是一个面向科研全流程的在线系统：从论文的管理、解析，到阅读、问答、检索、分析，再到写作，一站式完成。它已经部署在公网上，现在大家看到的就是真实运行的系统，文献库里有 23 篇真实论文。下面我按科研工作的顺序演示六个模块。"

---

## 0:40–2:00 模块一：PDF 管理 · 语义去重 · 版本差异（测试用例 3.1）

**画面与操作**：
1. 滚动文献列表，指向《Attention Is All You Need》两张卡片（各 15 页）
2. 点"去重扫描"→ 等转圈结束
3. 指出两张卡的徽章"同工作 · 建议保留 v7"
4. 点其中一张的"版本差异"→ 弹窗出现后停留
5. 鼠标划过 LLM 差异总结要点和章节差异列表
6. 点"保留全部"关闭弹窗

**台词**：
"第一个模块是 PDF 管理与细粒度解析。上传的每篇 PDF 会按内容哈希入库，并解析出标题层级、公式、表格和参考文献。这里有个典型场景：同一篇论文的 v1 和 v7 两个版本都在库里。我点去重扫描——系统用正文相似度判定它们是同一份工作，给出建议保留 v7，依据是 arXiv 版本号。再点版本差异，系统把两个版本按章节对齐，用大模型生成中文差异总结：比如 Abstract 从一千一百字符增加到两千二百字符、Multi-Head Attention 一节细节扩充。最后由用户决定覆盖旧版还是保留全部。这正是赛题测试用例 3.1 的完整流程。"

---

## 2:00–3:30 模块二：抗幻觉 RAG 问答

**画面与操作**：
1. 点顶部"AI 问答"
2. 勾选"限定当前文献"，选《Attention Is All You Need》
3. 输入："Adam optimizer 的 beta1 和 beta2 是多少？"回车
4. 指着逐字出现的流式回答，再指着下方溯源卡（引文、页码、相似度）
5. 点溯源 → 跳到阅读器原文位置 → 点"AI 问答"切回，强调对话还在
6. 追问："它的上下文窗口是多少？"（不点限定）回车
7. 指着回答里的"它"被正确理解为上一问的对象

**台词**：
"第二个模块是问答。我限定在这篇论文里问一个细节问题。注意回答是逐字流式的——这是 Token 级流式输出。每个结论后面带溯源标记，下面的溯源卡显示原文引文、页码和相似度。我点溯源跳到原文核对——再切回问答，对话完整保留，不会丢。再追问一句'它的上下文窗口是多少'，注意'它'指的还是刚才那篇论文：系统带多轮记忆，能还原指代，追问是连贯的。答案锚定原文出处，不确定就明确说找不到，从机制上抑制幻觉。"

---

## 3:30–4:30 模块三：版式感知阅读 + 联动翻译

**画面与操作**：
1. 阅读器里点缩放"+"两次，展示原版排版（公式、双栏）
2. 点右侧翻译面板"整篇翻译"（若已译完就点"刷新进度"显示 77/77）
3. 指着左右对照的原文块和译文块
4. 点右上角"放大"→ 全屏对照层：左边真 PDF 原页、右边大字译文
5. 滚动两三屏，展示左右按页对齐
6. Esc 或点关闭退出

**台词**：
"第三个模块是阅读和翻译。阅读器是 PDF 原版渲染，公式、图表、双栏排版不失真。右侧是按语义块对齐的双语对照翻译，支持单句、单页、整篇三种粒度，整篇翻译有实时进度。点放大进入全屏对照：左边是论文原页——图片、公式都在——右边是大字译文，两边按页对齐滚动。读英文长文的时候，这个体验是沉浸式的。"

---

## 4:30–5:30 模块四：自动检索追踪推荐

**画面与操作**：
1. 点"检索推荐"
2. 搜索框输入 "mixture of experts" 或 "reinforcement learning from human feedback"，点搜索
3. 指着结果列表：双源合并、含金量筛选说明、GitHub 链接
4. 对一条结果点"赞"，说反馈会调权重
5. 点"一键入库"（选一篇），说明它会进入文献库被问答/图谱复用
6. 指着追踪区："arXiv 追踪"

**台词**：
"第四个模块是检索推荐。系统并行查询 Semantic Scholar 和 arXiv 两个来源，合并去重后排序。这里有个学术细节：引用含金量筛选——把礼节性引用过滤掉，留下真正有学术价值的参考文献，还会发现论文的 GitHub 代码链接。用户可以点赞点踩，反馈会写入数据库影响后续排序。看中的论文一键入库，和问答、图谱打通。还可以追踪 arXiv 条目，定期检查新版本。"

---

## 5:30–6:30 模块五：引用图谱 + 综述

**画面与操作**：
1. 点"引用图谱"→ 点"构建图谱"
2. 图谱出来后指着几个中心节点
3. 点"分析"：展示 PageRank 排名和解读
4. 点"综述"或"Future Work"，展示生成结果

**台词**：
"第五个模块是引用图谱挖掘。系统从每篇论文的引用上下文里提取引用关系，构建引用网络。分析时用 PageRank、度中心性、中介中心性三类指标找出领域的基石论文，再由大模型做主题分类和解读——回答'这个方向的奠基之作是哪几篇'。还能提取 Future Work 并去重追踪，最后生成文献综述，直接服务写作。"

---

## 6:30–7:30 模块六：写作 Copilot

**画面与操作**：
1. 点"写作 Copilot"
2. 输入主题生成大纲
3. 选 Mermaid 画一个示意图，展示生成的代码
4. 选 CSV 数据生成图表，指着英文 Figure Caption

**台词**：
"第六个模块是写作辅助。输入研究主题生成论文章节大纲；示意图支持 TikZ、Graphviz、Mermaid 三种格式——注意生成的代码会做骨架校验，杜绝'看起来像代码'的幻觉输出。图表由 CSV 数据确定性构建，永远合法，大模型只负责提炼英文图注。还有参考文献格式化和中译英学术化。"

**台词**：
